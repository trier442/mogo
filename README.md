# 모두의 모의고사 v20 - 애드센스 친화형 기출 분석 사이트

이 버전은 단순 PDF 링크 모음이 아니라, 각 시험별 분석 페이지를 함께 제공하는 구조입니다.

## 구성
- `index.html`: 메인 자료실
- `analysis/`: 시험별 분석 페이지
- `assets/`: 디자인과 검색 기능
- `data/`: 시험 데이터
- `legal/`: 소개, 개인정보처리방침, 문의 페이지
- `scripts/`: 링크 수집 스크립트

## GitHub Pages 업로드
이번 버전은 분석 페이지가 있으므로 `index.html` 하나만 올리지 말고 폴더 전체를 올리세요.

업로드해야 할 것:
- index.html
- assets/
- analysis/
- data/
- legal/

## 애드센스 측면
PDF 버튼은 보조 기능으로 두고, 각 시험별 분석글·학습 전략·오답 정리법을 함께 제공하는 구조입니다.
